# Lab6

## Overview
In this lab you will implement a `BinaryTree` class that stores `int` values. You write eight methods. Three methods measure the tree. Two methods search the tree. And three methods list, change, and check the tree. The key idea to remember is that every subtree is itself a binary tree, so most methods solve the problem for the two subtrees and then combine their answers.

### Level-order notation
`Main` tree writes a tree as a list such as `[5, 9, 2, 6, null, 8, 1]`. Read it level by level, from left to right. The first value is the root. After it come the children of each node in turn, left child first, with `null` for a missing child. The children of a missing node are not listed, and `null`s at the end of the list are left out. `[]` is the empty tree. `BinaryTree.fromLevelOrder(5, 9, 2, 6, null, 8, 1)` builds a tree from this notation, and `toString()` writes a tree in it. 

## Objectives
- Writing recursive methods on binary trees.
- Traversing a tree in order, changing its structure, and checking the binary search tree property.
